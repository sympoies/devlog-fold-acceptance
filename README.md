# devlog-fold-acceptance

Disposable acceptance repository for the agent-runtime-kit devlog fragment layout and its scheduled fold workflow (sympoies/agent-runtime-kit#218).

It exercises, against a protected default branch with required signed commits, two pull requests that each add a devlog entry merging in either order, the scheduled fold (no-op, normal, stale-parent retry), and the fold actor's verified commits.

Not a product. Contents are test fixtures.
